# ログ — 行動記録アプリ

1日の行動を縦型（バーチカル）のタイムラインで記録し、あとから振り返るためのアプリです。
ブラウザだけで動く PWA なので、ホーム画面に追加すればスマホアプリのように使えます。

## できること

- **バーチカルタイムライン** — 24時間の縦軸に、記録をブロックで表示
- **2種類の記録**
  - **期間** … 睡眠・仕事など、始まりと終わりがあるもの（日をまたぐ記録にも対応）
  - **点** … 服薬など、その瞬間の出来事
- **継続中の記録** — 終了時刻を空にして開始し、あとから「終了」ボタンで締める
- **サマリー** — 7 / 30 / 90 日の日別グラフ、カテゴリ別の合計時間・回数・平均
- **検索・絞り込み** — メモとカテゴリ名での検索、カテゴリでの絞り込み
- **カテゴリ管理** — 名前・色・既定の記録方法（期間 / 点）を自由に編集
- **オフライン動作** — Service Worker でアプリ本体をキャッシュ

## 公開先

`main` ブランチに変更が入ると GitHub Actions（`.github/workflows/pages.yml`）が
自動で GitHub Pages にデプロイします。

- 公開 URL: https://shogotanihara-cpu.github.io/Claude/

Pages が未設定の場合はワークフローが自動で有効化します（`configure-pages` の `enablement`）。
うまくいかないときは **Settings → Pages → Build and deployment → Source** を
**「GitHub Actions」** に手動で変更してください。

## ローカルで動かす

静的ファイルだけで動くので、Web サーバーに置くか、ローカルで配信します。

```bash
python3 -m http.server 8000
# → http://localhost:8000/index.html
```

スマホで使うときは、上記の URL をブラウザで開き、共有メニューから
「ホーム画面に追加」を選ぶとアプリとして起動できます。

> Service Worker は `https://` または `localhost` でのみ動きます。
> `file://` で直接開いた場合、アプリ自体は動きますがオフラインキャッシュは無効です。

## データについて

記録は **端末のブラウザ内（localStorage）にのみ** 保存されます。サーバーには何も送られません。

- 端末やブラウザをまたいだ同期はされません
- ブラウザのデータ削除や機種変更で消えます
- 設定画面の「バックアップを保存」で JSON として書き出し、「復元」で読み戻せます

## ファイル構成

```
index.html              画面の骨格
css/style.css           スタイル（ライト / ダーク自動切り替え）
js/store.js             データ層（localStorage の読み書き）
js/ui.js                日付ユーティリティと共通UI部品
js/timeline.js          バーチカルタイムラインの描画
js/summary.js           集計とグラフ
js/app.js               画面制御
manifest.webmanifest    PWA 設定
sw.js                   Service Worker
icons/                  アプリアイコン
```

## データ構造

```js
// ログ1件
{
  id:    "l...",           // 自動採番
  catId: "c1",             // カテゴリID
  type:  "span" | "point", // 期間 / 点
  start: 1757203800000,    // 開始（epoch ミリ秒）
  end:   1757232600000,    // 終了。null なら継続中。point では常に null
  memo:  "ログアプリの設計"
}

// カテゴリ
{ id: "c1", name: "睡眠", color: "#6366f1", kind: "span" }
```
