## 進め方

1. **面白さの類型**（済）── どんな快があるのかを先に並べる
2. コンセプト ── 主役にする型を 1 つ決め、狙わない型を明言する
3. コアループ ── 「何をすると何が起きるか」を秒・分のスケールで決める
4. 検証 ── 時間軸の 5 層に穴がないか、スクショ 1 枚で伝わるかを確認する
