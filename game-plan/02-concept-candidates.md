# コンセプト候補（未決定）

[01-fun-typology.md](01-fun-typology.md) の 8 類型のうち、
**個人開発 × App Store で勝ち目のある 4 つの型**それぞれに、実際に作れる案を落とした。
まだどれにも決めていない。主役の型を 1 つ選ぶための材料。

各案は、類型の言葉で次の 5 つを埋めてある。

- **コアループ** ── 「何をすると何が起きるか」を一文で（宮本茂の順番。秒・分から作る）
- **主役＋支え** ── 主役 1 ＋ 支え 2。それ以外は狙わないと明言する
- **時間軸** ── 5 層のどこが埋まり、どこが空くか
- **売り方** ── ストアで何が伝わるか、価格の形
- **いちばん重いところ** ── 開発の山と、失敗するとしたらどこか

---

## 案A ── 主役「驚き」：ルールがふえる

**コアループ**
盤に駒を 1 つ置く → 置いた瞬間、盤のルールが 1 つ書き換わる → 書き換わった盤で次の一手を考える。

毎手番が「期待をつくる → ずらす → 回収する」そのものになる。
プレイヤーは常に先を読まされ、常にずらされ、しかし**ルールを読めば必ず筋が通る**。
回収があるので「理不尽」にならない、というのがこの案の生命線。

| 項目 | 内容 |
|---|---|
| 主役＋支え | 驚き ＋ 発見（ルール同士の相互作用がわかる）／上達（読みの精度が上がる） |
| 狙わない | 没入・つながり・自由 |
| 1 プレイ | 3〜5 分。1 日に何回でも |
| 時間軸 | 秒△ 分◎ 時◎ 日○ 週月△ |
| 売り方 | 買い切り。記号とタイルだけで成立するので絵のコストがほぼゼロ |
| いちばん重い | ルールの組み合わせ爆発の検証。**ルール同士が矛盾したときの裁定を先に決めないと破綻する** |
| 失敗するとしたら | 「ずらす」だけ強くて「回収」が弱く、運ゲーに見えるとき |

**別案** 証言が 1 つだけ嘘の推理もの。嘘のつき方のパターン自体が毎回変わる。

## 案B ── 主役「上達」：ワンボタンの壁登り

**コアループ**
画面を押した長さだけ跳ぶ → 足場に乗れば上へ、外せば少し落ちる（全部は落ちない）→ すぐ次を跳ぶ。

運の要素をゼロにして、**失敗の原因が 100% 自分にあると分かる**状態を作る。
即リトライ・低い失敗コスト・自己ベストの 3 点だけで、有能感は成立する。

| 項目 | 内容 |
|---|---|
| 主役＋支え | 上達 ＋ 手触り（押した感触と跳ぶ返り）／予感（あと 1 マスで自己ベスト） |
| 狙わない | 没入・自由・運 |
| 1 プレイ | 1〜3 分。何度でも |
| 時間軸 | 秒◎ 分◎ 時○ 日△ 週月△ |
| 売り方 | 買い切り。**高評価レビューを生むのはこの型**（「クリアできたときの達成感が」と書かれる） |
| いちばん重い | 難易度カーブ。**ステージの手作業が開発量の大半になる** |
| 軽くする手 | ステージを手作りせず、生成＋「クリア可能性を保証する検証器」で量を出す |
| 失敗するとしたら | 階段が急すぎて、上達ではなく理不尽に転ぶとき |

**別案** リズムに合わせたワンボタン。ただし譜面制作コストが重く、案Bより不利。

## 案C ── 主役「意味」：1 日に 1 手だけ指せる盤

**コアループ**
1 日 1 回だけ、盤に一手を置ける → その一手は永久に残る → 1 年かけて、盤が 1 枚の絵になる。

「意味」は絵も物量もサーバーも要らない、いちばん割のいい増幅器。
**日・週月の層が最初から埋まる**のがこの案の強みで、リテンション設計をあとから足す必要がない。
`log/` `wake/` で培った「記録して意味を持たせる」設計がそのまま活きる。

| 項目 | 内容 |
|---|---|
| 主役＋支え | 意味 ＋ 予感（明日どうなるか）／自由（誰の盤とも違う盤になる） |
| 狙わない | 手触り主導・つながり・運 |
| 1 プレイ | 1 日 30 秒。1 年で完成 |
| 時間軸 | 秒△ 分× 時× 日◎ 週月◎ |
| 売り方 | ストアのスクショで**完成した盤の多様性**を見せられる。買い切りが成立するか要検討 |
| いちばん重い | **秒・分の層がガラガラ**なこと。30 秒しか触らない体験の手触りをどう作るか |
| 失敗するとしたら | 1 日目に「これは何が面白いのか」が伝わらず、2 日目が来ないとき |

**別案** 現実の行動を記録すると図鑑が埋まる。ただしゲームというより道具寄りで、`log/` と食い合う。

## 案D ── 主役「手触り」：崩す

**コアループ**
指でなぞる → なぞった線に沿って物が崩れる → 崩れ方と音が毎回違う。

App Store のスクショと 15 秒動画で伝わる、数少ない型。初回起動の離脱をいちばん防げる。
ただし単体では 10 分で飽きるので、最初から他の型と組む前提で設計する。

| 項目 | 内容 |
|---|---|
| 主役＋支え | 手触り ＋ 発見（崩し方のパターンが見つかる）／意味（崩した素材が集まっていく） |
| 狙わない | 上達・つながり |
| 1 プレイ | 1〜10 分 |
| 時間軸 | 秒◎ 分○ 時△ 日△ 週月△ |
| 売り方 | 動画が最も強い。無料＋課金にも買い切りにも振れる |
| いちばん重い | 物理演算と端末性能。**遅延が 100ms 出た時点でこの案の価値はゼロになる** |
| 失敗するとしたら | 気持ちいいだけで構造がなく、10 分で終わるとき |

## 現時点の見立て

**案A を推す。** 理由は 3 つ。

1. 類型の経験則「安い型から積む」に最も素直。驚きは設計だけで作れて、絵の物量が要らない
2. 支えに置いた発見・上達も同じ盤の上で成立するので、**1 つの実装で 3 つの型が出る**
3. 買い切りで成立し、運（劇物）を 1 滴も使わずに済む

弱点は「ストアで伝わらない」ことだが、これは案A を捨てる理由ではなく、
**別途スクショと動画の設計を 1 項目として立てる**ことで対処する。

次点は案C。日・週月の層が最初から埋まるのは他の 3 案にない強みで、
既存アプリで培ったものがそのまま効く。ただし秒・分が空なので、先に手触りの解を出す必要がある。
