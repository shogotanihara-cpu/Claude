# ブログ記事アイキャッチ画像の仕様・生成

WordPressブログのアイキャッチ画像（記事一覧やSNSシェア時に表示されるサムネイル）を、仕様に沿って効率よく作るためのスキル。

## なぜ「メーカーツール」を作るのか

記事は今後何十本と増えていく。毎回Claudeが個別に画像を1枚ずつ生成していては非効率だし、トンマナ（配色・レイアウト）がブレる。そこで最初に、**タイトル・カテゴリー・アクセントの色を入力すると規定サイズの画像を生成できるツール自体をArtifactとして1つ作る**。以後はユーザー自身がそのツールを開いて、記事タイトルを打ち込むだけで量産できるようにする。これによって、記事を書くたびにClaudeとやり取りしなくても画像が作れるようになる。

## 仕様

- サイズ: **1200×630px**（OGP/SNSシェア・WordPressのアイキャッチ標準サイズ）
- カテゴリーごとに色を割り当て、記事一覧を眺めたときにカテゴリーが一目で分かるようにする（例: 「準備」系はインディゴ、「グッズ」系は別の色、というように、サイトのカテゴリー数だけ配色パターンを用意する）
- 構成要素の例: カテゴリー名（バッジ状に）、記事タイトル（大きく）、キャッチーな一言フック（あれば）。素材写真は使わず、テキストと図形だけで構成すると著作権の心配がなく量産しやすい
- **公式のロゴ・キャラクター画像・グッズ写真などを無断で使わない**。ファンブログ等では特に、対象コンテンツの公式素材を転載しないよう明記しておく

## 進め方

### 1. 初回: メーカーツールを作る
HTML/CSS/JS（`<canvas>` またはSVG）で、以下ができるArtifactを1つ作成する。
- タイトル・カテゴリー名・（必要なら）フック文言を入力するフォーム
- カテゴリー名から自動で配色を決める、またはカラーピッカーで選べる
- 1200×630でプレビュー表示し、画像として保存できる（`<canvas>` の `toDataURL` などで書き出し）

あわせて、「アイキャッチとは何か」「なぜこのサイズなのか」を説明する簡単なガイドも添えると、ユーザーが自分で使うときに迷わない。

### 2. 以降: 個別記事のアイキャッチが必要なとき
既にメーカーツールがある場合は、新しく画像を作るのではなく「メーカーツールにこの内容を入力してください」と案内する（カテゴリー名・タイトル・配色の組み合わせを具体的に伝える）。ツールが無い、または大幅に仕様を変えたい場合のみ、上記の手順1からやり直す。

### 3. サンプルを添える
新しくメーカーツールを作ったときは、主要カテゴリーごとに1枚ずつサンプル画像を生成して見せると、ユーザーが仕上がりイメージを掴みやすい。

## 気をつけること

- Artifactとして作る画像生成ツールは、記事が増えても使い続けるものなので、レイアウトや配色ルールは最初にある程度固めておく。あとから毎回デザインを変えると「カテゴリーで色分けする」意味が薄れる。
- 生成した画像そのものをチャットで大量に貼るより、ツールへのリンクを渡して「必要な分だけユーザー自身が量産できる」状態にする方が、長期的な運用コストが低い。
