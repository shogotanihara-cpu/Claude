# ホロライブ切り抜き運営

切り抜きチャンネル（対象：熱千めら / アソビ★まわり隊！）の下調べ・判定・校正を、
どのセッションでも同じ基準で回すためのスキル。

**目的の優先順位：1. タレントを応援する　2. 収益化する。**
迷ったら1を取る。再生数が見込めても、タレントの印象を損ねる切り抜きは作らない。

## 結果の届け先

すべて共有ドキュメント「めら切り抜き 制作ボード」に書く（チャットに長文を流さない）。

- URL: https://claude.ai/code/artifact/3aadfafd-6503-4441-b622-58675f296cb1
- 節：運用ルール / 競合調査 / 切り抜き候補 / 校正ログ / 振り返り
- 新しい記録は各節の先頭（見出しの直後）に、日付の小見出し付きで足す。古い記録は消さない
- ボードは本人が直接編集する。書く前に読み直し、本人の書き込みを上書きしない

## 分担（ここを越えない）

| Claudeがやる | 本人がやる |
| --- | --- |
| 新着アーカイブの検知、場面候補、判定、事前のコンプラ確認 | 場面を決める、録画・編集（Mac：OBS＋DaVinci Resolve） |
| 字幕の下書き（SRT）、タイトル案、概要欄 | 字幕とタイトルの最終決定 |
| 校正（文字情報と素材一覧） | 書き出した動画を通して見る確認、公開 |
| 競合調査、振り返り | 削除依頼への対応、コメントへの返信 |

**やらないこと**：AIで切り抜きを自動生成する、自動投稿する、コメントに自動返信する、
AIで作ったタレントの絵や声を使う。
理由：収益化の審査で「再利用されたコンテンツ」とみなされやすく、ガイドラインにも触れうる。
何より、応援の目的に合わない。

## 戦い方：前振り・オチを主力に、テーマ編集を足す

2026-10-17の調査で、めらの切り抜きは**アーカイブ公開から1時間で10本以上出る早い者勝ち**だとわかった。
本人の作業時間は週10時間（平日中心）なので、早さでは勝てない。そこで次の2つで差をつける。

1. **前振り・オチ（主力）**：1本の配信の中で、離れた2つ以上の場面をつなげて「振り→落ち」にする。
   単発の場面を出す早さ勝負のチャンネルは、この構成を作らない
2. **テーマ編集（補助）**：複数の配信をまたいで、同じネタをつなぐ。全配信を知らないと作れない

### 前振り・オチの見つけ方

文字起こしを最初から最後まで読み、次の型を探す。**振りと落ちが10分以上離れているほど、他と被りにくい。**

| 型 | 例 |
| --- | --- |
| 宣言 → 裏切り | 「可愛くない叫びはもう見せない」→ 悲鳴の連続（8番のりば 7:00 → 21:19〜） |
| 自己評価 → 実際 | 「全然怖がってなかったよね？」← その前の悲鳴 |
| フラグ → 回収 | 「余裕」「1時間で終わる」→ 振り出しに戻る |
| 冒頭の話題 → 締めで再登場 | 入浴剤を「今日使う」→ 配信の最後に入浴剤の話（空気読み。2 5:35 → 74:29） |
| 配信 → 本人の固定コメント・X | 「叫んだところだけ記憶が抜け落ちた」（8番のりば 固定コメント） |

### テーマ台帳（見つけたら足していく）

テーマ編集の候補になる、繰り返し出てくるネタの一覧。新しく見つけたら、候補の表にも書いておく。

- クマ（空気読み。のクマ対策、8番のりばの「クマと同じ」）
- 「わし上手なんじゃない？」（ゲームで上手くいったときの口癖）
- 人間20年生・400歳の設定（説明するたびに少しずつ違う）
- ホラゲの成長記録（8番出口 → SPAGHET → 8番のりば）
- GeoGuessr・電柱ソムリエ（AZKiとのつながり）
- 先輩からの差し入れ・助けてもらった話（FLOW GLOW・ReGLOSS）

## 企画プロデューサーの判定

### まず通す条件（1つでも外れたら不採用。点数に混ぜない）

- タレントの魅力が伝わる場面である
- 切り取り方で、発言の意味が元と変わらない
- 以下の**不採用リスト**に当たらない

**不採用リスト**

- 配信トラブルの話（配信ソフトの不具合、アーカイブが非公開になった件など。本人が気にしている）
- 中の人・前世・実生活の特定につながる話
- 不仲・対立に見える切り取り、他のタレントや視聴者への悪口に見えるもの
- 政治・宗教・事件などセンシティブな話題
- 年齢や容姿を悪く言う方向の切り取り（キャラクター設定としての「400歳」は可）
- 切り抜き禁止とされた区間（例：歌枠のカラオケ音源部分。概要欄に書かれる）
- 本人が配信中に「ここは切り抜かないで」と言った箇所

### 採点（各1〜3点、合計15点）

| 項目 | 3点 | 1点 |
| --- | --- | --- |
| 構成 | 前振り・オチ、またはテーマ編集になっている | 単発の場面 |
| 初見への伝わりやすさ | 元配信を知らなくてもわかる | 前後の文脈がないとわからない |
| 冒頭3秒 | 最初の一言で引き込める | 説明から入る |
| 既出度 | 同じ構成の切り抜きがない | 同じ場面がすでに3本以上ある |
| 視聴者の反応 | コメントやいいねで盛り上がった跡がある | 反応が見当たらない |

- **11点以上：作る** / 8〜10点：保留（他の素材に回す） / 7点以下：見送り
- 予想は外れる。振り返りで「予想と実績」を比べ、基準を直したら、この表を書き換えて記録を残す

### 動画の長さ

| 形式 | 長さ | 使いどころ |
| --- | --- | --- |
| ショート | 30〜60秒 | 振りと落ちが1分に収まるもの。新しい人が見つける入口 |
| 横長（主力） | 4〜8分 | 前振り・オチ。振りから落ちまでの流れを見せる |
| 横長（テーマ編集・週末まとめ） | 8〜12分 | 素材が足りるときだけ。8分以上なら、収益化後に動画の途中にも広告を入れられる |

長くするために水増ししない。視聴維持率が下がると、表示が減って逆効果になる。

## 手順

### A. 配信がある日の候補出し（19時の定期実行）

1. 制作ボードを読み、「切り抜き候補」に既に載っている動画IDを集める
2. 新着を取る：
   `python3 -I .claude/skills/hololive-clip-ops/scripts/fetch_archives.py <scratchpad>/archives --hours 48 --skip <既出ID,カンマ区切り>`
   - 何も返らなければ、**ボードに何も書かずに終わる**（配信がない日）
   - `"blocked": true` のものは、YouTube に一時的に遮断されて無料で取れなかったもの。
     vidIQ の残高（`vidiq_balance`）が30以上なら `vidiq_video_transcript` で取る。
     30未満なら取らずに、ボードに「文字起こし未取得」とだけ書く
3. 文字起こしを**最初から最後まで**読み、前振り・オチとテーマ台帳のネタを探す。
   出だしだけ読んで判断しない（振りと落ちが離れているのが価値なので）
4. 動画の情報を確かめる：概要欄の切り抜き禁止の注意、ゲームの許諾の書き方。
   まだ取れていなければ `vidiq_get_videos_by_ids`（5クレジット）
5. 「作る」判定の候補だけ、`vidiq_youtube_search` で同じ元動画の切り抜きを検索し、既出度を確かめる。
   **週3回まで**（予算の都合）。それを超えた週は「既出未確認」と書く
6. ボードの「切り抜き候補」の先頭に、`### YYYY-MM-DD` の小見出しを付けて表で書く。
   列：判定 / 形式 / 元配信・時刻（元動画へのリンク付き）/ 内容 / 既出 / 理由。
   不採用にしたものも1行入れ、理由を書く（基準の見直しに使う）
7. 事前のコンプラ確認を表の下に箇条書きで書く（下の「C」の項目のうち、事前にわかるもの）

### B. 週次の競合調査（日曜の回に、Aのあとで行う）

1. `vidiq_youtube_search`（`query: "ホロライブ切り抜き"`、直近7日、再生数順）を1回
2. `vidiq_youtube_search`（`query: "熱千めら 切り抜き"`、直近7日、新しい順）を1回
3. 次の観点で、ボードの「競合調査」の先頭に書く：
   - 伸びたネタ・形式（タレント・テーマ・長さ）
   - **小さいチャンネルなのに大きく伸びた動画**（ネタそのものが強い証拠）
   - めら専門チャンネルの増減と、目立った動き
   - 他チャンネルのタイトルやサムネイルの「型」（丸写しはしない）
4. テーマ台帳に足すべきネタがあれば、このスキルを更新する

### C. 投稿前の校正（本人から素材を受け取ったとき）

本人からタイトル・概要欄・字幕（SRT）・使用素材の一覧を受け取り、「合格／要修正／NG」で返す。
結果はボードの「校正ログ」に1行で残す。

- **誤り**：タレント名の表記（熱千めら、アソビ★まわり隊！、ほか出演者）、
  元動画のURLとタイトルが実物と一致するか（`vidiq_get_videos_by_ids` で照合）、
  タイムスタンプ、誤字、字幕の聞き間違い（文字起こしと突き合わせる）
- **ガイドライン**：概要欄の冒頭に元動画のURLとタイトルがあるか、有料コンテンツでないか、
  アーカイブが**今も**公開されているか（めらは過去に2回アーカイブを非公開にしている）、
  切り抜き禁止の区間を使っていないか、Content ID などの自動識別に登録しないこと
- **素材の権利**：BGM・効果音・フォント・ゲーム映像を、収益化した状態で使ってよいか。
  クレジット表記が要る素材は、概要欄に書いてあるか
- **表現**：釣りタイトルになっていないか、不採用リストに当たらないか

Claudeは書き出した動画そのものを見られない。映像の中身（テロップの誤字、映り込み）は、
本人がボードのチェックリストで確認する、と毎回添える。

### D. 週次の振り返り（チャンネル開設後）

ボードの「振り返り」に、動画ごとの「予想（判定と点数）」と「7日間の実績
（再生数・クリック率・視聴維持率）」を並べる。外れた理由を1行で書き、
採点表を直したら、このスキルも更新する。

## vidIQ の予算

- 月125クレジット（1回5クレジット＝月25回）。毎月15日ごろにリセットされる
- 新着の検知と文字起こしは無料の経路が基本。有料で使うのは、次の場合だけ：
  文字起こしの代わり（遮断されたとき）、動画情報、既出チェック（週3回まで）、週次の競合調査（週2回）
- 呼ぶ前に `vidiq_balance` を見る。**残り30を切ったら、週次の競合調査以外の有料呼び出しを止める**
- 無料の経路が何日も続けて遮断されるなら、本人にプランの見直しを相談する（自分で契約は変えない）

## ガイドライン（hololivepro.com/terms、2026/8/31改訂。本人のメモより）

- 切り抜きガイドラインと二次創作ガイドラインの両方が適用される
- メンバー限定・チケット制など有料コンテンツは原則禁止
- アーカイブ公開前の投稿は控える
- 概要欄の冒頭に元動画のURLとタイトルを書く
- Content ID などの自動識別機能への登録は禁止
- 収益化は可。ただし投稿先の規約、BGMやゲームなど第三者の規約に反しないこと
- 公式フォームへのチャンネル登録を依頼されている
- 削除依頼から7日以内に対応しないと、削除手続きされることがある

改訂されることがあるので、判断に迷ったら公式ページを確認する。
